# DevOps SDG Healthcare Project

## 🌍 SDG Goal
SDG 3: Good Health and Well-being

## 💡 Project
Healthcare risk prediction system using Flask + React

## ⚙️ Tech Stack
- Flask
- React
- GitHub Actions
- Render Deployment

## 🚀 Features
- Predict health risk
- Full stack application
- CI/CD pipeline

## ▶ Run Backend
cd backend
pip install -r requirements.txt
python app.py

## ▶ Run Frontend
cd frontend
npm install
npm start
